# 改版说明：规程 · 印章

## 任务
用户要求“现在前端设计换一下”。存量系统：管理后台（Element Plus，1440 桌面）+ 员工端 H5（Vant，390 手机），原设计是绿色 SaaS 卡片风。

## 方向
把界面当作一本正在被批注的规程手册：纸张底色、墨色文字、朱红印章色；用 1px 分隔线组织层级，不用卡片阴影和大圆角；标题用衬线字，数字用等宽无衬线；后台导航像手册目录，员工端像索引卡。

选择理由：这个产品的核心对象是《煤矿安全规程》与隐患处置单据，纸+印章比通用面板更贴题；同时细分隔线比阴影更适合高密度表格，离线环境下只依赖系统字体。

## 令牌
- 纸 `#f2ece0`（页面） / `#fffdf6`（卡面） / `#faf6ea`（次级面）
- 墨 `#1d1a15` / `#4b4438` / `#7d7466`
- 线 `#ddd3bd`，强调线 `#bfae8c`
- 印章红 `#a5311f`（动作、选中、引用、超时），苔绿 `#47624b`（成功），赭 `#8a6a2f`（警示）
- 圆角统一 2px；无阴影
- 字体：标题 `Noto Serif SC / 宋体` 回退；正文与表格系统无衬线；数字 `tabular-nums`

## 结构变化
- 后台：深色侧栏 → 纸色目录式侧栏（分组 + 01–09 编号 + 朱红竖条选中）；页头 58px 细线分隔；看板从卡片堆改为报表式 KPI 行 + 指标条 + 口径表。
- 员工端：绿色渐变头图 → 墨色抬头；圆角白卡 → 纸面细线卡；入口用衬线单字；问答气泡改为墨块/纸面两种。
- 组件层：Vant 与 Element 的主色、圆角、占位符颜色统一在 `theme.css` 用 `:root:root` 覆盖（共享 chunk 先于组件库 CSS 加载）。

3. 顶部异常条 + 20 段刻度尺，100% 不再是通栏红线。已改。
4. 首屏“今天要办”卡，宫格 6→4，底栏加入问规程。已改。
5. 依据行去重、删掉复述句（桩提示词同步调整），动作仍是模型原文，未逐条结构化——列为未完成。
