# 员工端“大字版”设计说明

## 用户与场景

- 用户：35–55 岁矿工、安全员，低文化程度，很多人不会拼音打字。
- 场景：班前会、井口、井下休息点；单手操作，可能戴手套；强光/粉尘；4G 或矿内 WiFi，信号不稳。
- 任务：问一条规程、报一条隐患、看一眼今天要做什么。

## 一句话方向

**一屏三件事、一步一个动作**：把现在 5 个 tab、14–15px 正文的员工端，改成 3 个 tab、20px 起步、按钮 64px 高的“大字版”，让不会打字的人也能用“点”和“说”完成主要任务。

## 关键决定

| 项 | 现在 | 大字版 |
| --- | --- | --- |
| 正文字号 | 14–15px | 20–22px（答案正文 22px，行高 1.8） |
| 标题 | 18–20px | 28–32px（姓名 32px） |
| 按钮高度 | 44px | 64px 主按钮 / 56px 次按钮，间距 ≥ 12px |
| tab | 5 个 | 3 个（问、学、我），单字图标 + 大字标签 |
| 入口 | 4 宫格图标 | 1 个主按钮 + 2 个次按钮，每行都带说明 |
| 输入 | 文本框为主 | 语音优先（“说”按钮 60px），常用问题做成大号可点按钮 |
| 答案 | 条款号 + 小字正文 | 条款号 28px 印章块 + 22px 正文 + “读给我听” |
| 状态 | 只有 loading | 弱网/断网提示条、失败保留草稿、点错可返回 |

## 页面清单（实现时）

1. 首页：主按钮“问规程”、次按钮“报隐患/学规程”、今日待办卡、常问问题。
2. 问答页：问题气泡、条款号章、正文、“读给我听/再看原文”、常问 chips、大输入框 + 说话。
3. 上报页：拍照（大按钮）+ 3 个字段 + 提交。
4. 学习/考试页：一条一屏、大按钮“下一题”、进度大字。
5. 我的：姓名、部门、今日完成、退出。

## 实现状态

- 已落地：员工端首页、问答页、底部 3 tab、我的页「大字模式」开关（默认开启）、
  问答「先做」数字命中提升、引子句移到依据块、tabbar 安全区。
- 证据：`home.png` / `ask.png`（390×844 DPR2）；接口 103 项、浏览器 39 项回归全过。
- 独立评审：7.5 分，三条必修（tabbar 遮挡、结论不前置、待办数字口径）已改，
  可选项「有用/没用」已放大。
