# 前端说明

两个入口、一套代码库，构建产物通过 `go:embed` 打进服务端二进制，部署时只有一个可执行文件。

## 入口与地址

| 入口 | 地址 | 组件库 | 面向 |
| --- | --- | --- | --- |
| 员工端（H5） | `/`（history 路由，例如 `/ask`、`/learn/3`） | Vant 4 | 手机浏览器，井口与班前会现场 |
| 管理后台 | `/admin/`（例如 `/admin/docs`） | Element Plus 2 | 桌面浏览器，安全科与区队管理 |

同一进程同时托管两个入口：Go 侧的 `web.Handler` 判断 `/admin` 前缀决定回退到哪个 `index.html`，`/assets/*` 直接返回静态文件并带一年强缓存，`/api/*` 的未知路径仍返回 JSON 404。

## 开发与构建

```powershell
cd web
pnpm install            # 首次
pnpm dev                # 开发服务器 :5173，/api 代理到 :8080
pnpm build              # 产出 web\dist（会被 go:embed 打包）
pnpm verify:ui          # 无头浏览器回归（Edge/Chrome）
```

改完前端要重新编译服务端才会生效：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-web.ps1
```

`pnpm dev` 期间可以在 5173 端口调试，不需要每次重编二进制；生产/演示走 8080 的内嵌产物。

## 设计约定

### 方向：规程 · 印章

界面被当作一本正在被批注的规程手册，而不是通用 SaaS 面板：

- **纸与墨**：页面底色 `#f2ece0`，卡片纸 `#fffdf6`，正文墨色 `#1d1a15`，次级 `#7d7466`。
- **朱红只做动作与强调**：印章红 `#a5311f` 用于主按钮、选中态、引用条款和超时告警；成功态用苔绿 `#47624b`，警示用赭 `#8a6a2f`。
- **线而不是影**：去掉卡片阴影和大圆角（统一 2px），层级靠 1px 分隔线、留白和字号；表格头用纸色底，行间只用细线。
- **衬线做标题、无衬线做数据**：标题、KPI 数字、条款号用 `Noto Serif SC / 宋体` 回退栈，正文与表格用系统无衬线；数字统一 `tabular-nums`，报表里才能上下对齐。
- **后台导航像目录**：左侧纸色导航栏，分组（运行 / 知识与学习 / 隐患处置 / 系统），条目带 01–09 编号，选中用朱红竖条而不是整块高亮。
- **员工端像索引卡**：黑色抬头 + 纸面卡片，六个入口用衬线单字（问 / 学 / 考 / 宣 / 报 / 我）代替图标；问答气泡用户侧为墨块、助手侧为带细线的纸面。

这些令牌集中在 `src/shared/theme.css`，用 `:root:root` 提高优先级——共享样式被 Vite 抽成公共 chunk 后加载在组件库 CSS 之前，不提高优先级会被组件库默认值盖掉。Vant 与 Element 的圆角、占位符颜色、主色都在这里覆盖，页面里不再写死颜色。

### 改版要点（第二轮，按评审意见收敛）

第一版 7/10，主要问题集中在“换了壳但组件语义没换”。这一轮做了四件事：

1. **状态层收进纸墨朱**：`el-tag` 全部改为透明底 + 细框 + 墨字，成功用苔绿、警示用赭、失败用朱红；“超时 0”不再用危险色（0 不报警）。表格撤掉竖网格线，只留表头下与行间横线，读作簿册而不是 Excel。
2. **朱红分权**：主按钮保持朱红实底；行内操作（切片 / 查看 / 处理）一律墨色，悬停转朱红；只有破坏性操作（删除、驳回）默认朱红文字，并在二次确认里再次强调。
3. **看板先给异常**：顶部异常条（未闭环 / 超时 + 去处理）；三指标改为 20 段刻度尺，100% 是 20 根墨色刻度而不是一条通栏红线，低于 60% 才标朱红。
4. **员工端首屏给“今天做什么”**：抬头下方先是“今天要办”卡（去考试 / 去签收，无待办时引导问规程），六宫格缩为四宫格；底部导航从 4 个增到 5 个，把“问规程”放进主 tab。

第三轮补了两件事：

- **处置动作逐条**：提示词要求模型用 `1. 2. 3.` 每行一条列出动作，服务端把它们解析成 `actions[]`，正文只留说明与依据；员工端渲染成带印章序号的清单，紧急场景不用从散文里找动作。
- **盖章动效**：终态用印章表达——文档「已发布」、问题「已闭环」不再是彩色标签，而是一枚略微倾斜的朱红印章；只有状态刚变化时（发布成功、闭环成功）才播放 0.5s 压下动画，其余时候静态显示，并尊重 `prefers-reduced-motion`。

问答页同时收敛了信息：回答里的“依据：[第X条]”整行不再重复渲染，统一由正文下方的“依据”块承担，条款框点开即是原文。

### 其余约定

- **登录态**：`localStorage` 存 token 与用户快照，axios 拦截器统一加 `Authorization`；401 一律清空并回登录页。
- **返回按钮**：底栏 tab 用 `replace` 切换，进 `/ask` 时历史里没有上一条，`router.back()` 无处可退；问规程的返回改成“有上一条就 back，没有就回首页”，两条入口都能返回。
- **权限**：前台只做入口显隐，真正的判定在后端 `role_policy`；员工端与管理端分离，员工账号登录后台会被挡回。
- **数据范围**：区队长看到的是本部门数据，员工看到本人数据，由后端按 scope 过滤，前端不重复实现。
- **引用可追溯**：问答引用 chip 用 `chunk_id` 调 `/api/v1/chunks/:id/text` 取原文，与后台“复制原文”是同一份数据。

## 浏览器回归

`web/scripts/verify-ui.mjs` 用系统 Edge 的 DevTools 协议做真实渲染验证：注入登录态、打开页面、发一次真实提问并断言返回 `依据：[第X条]`、截图留档到 `docs/screenshots/`。

```powershell
node web\scripts\verify-ui.mjs --base http://127.0.0.1:8080
```
