【二】先跑起来（本机演示，三步）
--------------------------------------------------
1. 电脑装 Node.js 18+（https://nodejs.org）
2. 双击  server\填密钥.bat  → 把 DeepSeek 的 API Key（sk- 开头）填进 config.json
3. 双击  server\启动服务.bat
   窗口出现  http://127.0.0.1:8789  表示启动成功（这个窗口别关）
   浏览器打开  http://127.0.0.1:8789/login
   默认账号 sysadmin / secadmin / auditor，密码均为 coal2026（首次登录请立即修改）

微信开发者工具 → 导入项目 → 选择 miniprogram 目录 → 编译，即可看到界面。


【三】★ 甲方必须自己完成的六件事（乙方不代持）
--------------------------------------------------
1. 注册微信小程序（企业主体，营业执照）
   拿到 AppID / AppSecret 后填两处：
   · miniprogram\project.config.json 的 "appid"（现在是 touristappid 占位）
   · server\config.json 的 "appId" 和 "appSecret"

2. 服务器 + 已备案域名 + HTTPS 证书
   · 把 server 目录传到服务器，照 server\deploy\部署手册.md 配 systemd + Nginx
   · 域名要做 ICP 备案（7–20 个工作日），证书配好后是 https://api.你的域名.com
   · 小程序后台「开发管理 → 服务器域名」把这个域名加进 request 白名单

3. 改小程序的后端地址
   miniprogram\utils\config.js 的 baseUrl：
   · 本机演示（后端在同一台电脑）：http://127.0.0.1:8789
   · 手机真机调试：http://<服务器局域网IP>:8789（手机和服务器同一 WiFi）
   · 正式上线：https://<已备案域名>

4. DeepSeek API Key（甲方账号申请、自行充值）
   填 server\config.json 的 "apiKey"，或直接用环境变量 DEEPSEEK_API_KEY。
   密钥只保存在服务器本地，不要发微信、不要进代码库。

5. 语音转文字（可选功能）
   需要在甲方自己的小程序后台：设置 → 第三方设置 → 插件管理 →
   搜索「微信同声传译」添加，并把开发/运营成员加成开发者。
   加好之后，在 miniprogram\app.json 里加回这段再编译：
   "plugins": { "WechatSI": { "version": "0.3.5", "provider": "wx069ba97219f66d99" } }
   没加插件时，小程序里的语音按钮会自动退回「录音留言」模式，不影响其他功能。

6. 上线前改密码
   后台右上角「修改密码」，三个管理员账号都要改。

【五】常见问题
--------------------------------------------------
· 双击 bat 后浏览器打不开 → 先看黑窗口报错，或双击 诊断.bat
· 端口被占用 → 双击 停止服务.bat 再启动
· 小程序请求全红 → 开发者工具「详情 → 本地设置」勾选“不校验合法域名”
· AI 不回答 → config.json 里 apiKey 没填，或 DeepSeek 余额不足
· 手机上传照片失败 → 确认手机和服务器在同一 WiFi，且 baseUrl 是电脑的局域网 IP
· 想开机自启 → 右键「设置开机自启.bat」以管理员身份运行
