## 三步跑起来

### 1. 先起后端（不起的话问答页会提示连不上）

```powershell
cd ..\server
node index.js
```

详见 `../server/README.md`（填 DeepSeek 密钥、换知识库）。

### 2. 确认后端地址

`utils/config.js`：

```js
baseUrl: 'http://127.0.0.1:8789'
```

- **开发者工具模拟器**：用 `127.0.0.1` 即可（项目已设 `urlCheck: false`，不校验域名）
- **手机真机预览**：改成电脑局域网 IP，如 `http://192.168.1.20:8789`，且手机与电脑同一 WiFi
- **上线**：必须换 `https://` 且后端域名已备案，并加到小程序后台的合法域名里

### 3. 导入微信开发者工具

1. 微信开发者工具 → 小程序 → 导入项目
2. 目录选**本文件夹**（有 `project.config.json` 这一层）
3. AppID 用测试号，或你自己的 AppID
4. 点「编译」

## 功能说明

### AI 问答（真接口）

```
用户提问 → 后端检索知识库 top3 片段 → DeepSeek 按片段回答 → 前端逐字显示
```

- 密钥只在服务端，小程序里**没有任何密钥**
- 后端把命中的知识块作为 `cites` 返回，前端显示「依据 · 01-瓦斯防治」
- 网络失败 / 未配密钥 → 错误卡片，可「重试」或「转人工」
- 单次请求带最近 3 轮上下文，控制 token

### 答题（36 题，6 个岗位 × 6 题）

- 岗位：通用 / 采煤 / 掘进 / 通风 / 机电 / 运输
- 抽题：按岗位过滤 + 洗牌，每次 5 或 10 题
- 判分：选完立即出对错、解析、依据
- 错题：自动累积到 `wrongBook`（本地存储），个人中心可见
- 成绩：`quizBest` 记录最高分，同时上报 `/api/quiz` 入库

⚠️ **题库是示例内容**，正式上线前必须由矿安全科逐题审核，解析里的依据要换成矿上实际引用的条款号。
