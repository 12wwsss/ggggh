## 二、首次运行（三步）

1. 安装 Node.js LTS：https://nodejs.org
2. 双击 `server/填密钥.bat`，把 DeepSeek 的 API Key（以 sk- 开头）填入 `config.json`
3. 双击 `server/启动服务.bat`，浏览器打开 http://127.0.0.1:8789/api/health
   看到 `"key":"configured"` 即成功

## 三、小程序配置

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram` 目录
2. 在 `project.config.json` 里把 `appid` 换成 **甲方企业主体** 注册的 AppID
3. 修改 `miniprogram/utils/config.js` 中的 `baseUrl`：
   - 本机调试：`http://127.0.0.1:8789`
   - 手机预览：`http://<电脑局域网IP>:8789`
   - 正式上线：`https://<已备案域名>`（须在小程序后台加 request 白名单）

## 六、员工进入方式

打开小程序后，填写**姓名 + 手机号**即可进入，无短信验证、无微信授权：

- 手机号只存哈希 + 后 4 位，后台显示为 `****1234`，**全号不落盘**
- 同一手机号再次进入只更新最近时间，不重复建档
- 同一手机号改姓名会更新档案（记审计），适合填错后自行修正
- 后台「员工名册」自动列出所有进入过的人，可解绑、删除

## 六、员工端使用方式

小程序**打开即用**，不注册、不登录、不问姓名手机号：

- 每个人第一次打开自动生成一个本机标识，学习/答题数据记在这台手机上
- 换手机或清缓存会重新开始（如需跨设备，后续可接企业微信身份）
- 不收集任何个人信息，隐私合规上最省事

## 六点八、语音输入（可选）

小程序已接入**微信同声传译插件**实现语音转文字。启用步骤：

1. 登录 mp.weixin.qq.com → 设置 → 第三方设置 → 插件管理
2. 搜索「微信同声传译」→ 添加
3. 回到开发者工具重新编译

未添加插件时，长按语音按钮仍可录音并上传（只是不转文字），不影响其他功能。

## 七、常驻运行（不用每次开黑窗口）

**首次安装一次，以后开机自动跑，直接开浏览器即可。**

1. 双击 `server/设置开机自启.bat`（建议右键“以管理员身份运行”）
   - 优先注册 Windows 计划任务 `CoalMineAI`：**无窗口**、开机自启、崩溃自动重启
   - 若没有管理员权限，会自动退回到「启动文件夹」方式
2. 之后访问 `http://<服务器IP>:8789/login` 即可，无需再启动任何窗口

| 操作 | 文件 |
|---|---|
| 停止服务 | `server/停止服务.bat` |
| 取消开机自启 | `server/取消开机自启.bat` |
| 手动前台启动（调试用） | `server/启动服务.bat` |

运行日志：`server/data/server.out.log`

## 八、管理后台（首次登录请立即改密码）

1. 双击 `server/启动服务.bat`，浏览器会自动打开登录页
2. 默认账号：`sysadmin`（系统管理员）/ `secadmin`（安全管理员）/ `auditor`（审计管理员），密码均为 `coal2026`
   - 三员分立用于满足等保三级职责分离要求，各自权限互不重叠
3. **登录后点右上角「修改密码」**，改成矿上自己的密码（至少 6 位）
   - 改完所有设备需重新登录
   - 也可以直接改 `server/config.json` 里的 `adminPassword` 后重启服务
4. 登录后可进入两个页面：
   - `/admin` 管理后台：数据看板、知识库、题库、问题工单、考试成绩、制度宣贯、问答记录
   - `/qbank` 题库维护：安全科日常加题、改题、Excel 粘贴导入

> 默认密码只用于首次交付，请务必在验收前更换。
