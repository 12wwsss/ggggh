## 三步跑起来

### 1. 先起后端（不起的话问答页会提示连不上）

后端是 Go 单体服务（不是 Node）：

```powershell
cd ..
powershell -ExecutionPolicy Bypass -File scripts\dev.ps1   # 起数据库 + 编译 + 启动，默认 127.0.0.1:8080
# 或只起服务：.\bin\coalrag-server.exe（先配好 configs\config.json 或 COALRAG_DSN）
```

问答类功能需要矿内模型服务（llama-chat / llama-embed）在线，否则只走兜底话术。

### 2. 确认后端地址

`utils/config.js`：

```js
baseUrl: 'http://192.168.134.103:8080'
```

- **开发者工具模拟器**：本机服务用 `http://127.0.0.1:8080`（项目已设 `urlCheck: false`，不校验域名）
- **手机真机预览**：用服务器局域网地址，如 `http://192.168.134.103:8080`，手机与服务器同一 WiFi，并在小程序里打开调试
- **上线**：必须换 `https://` 且域名已备案，并加到小程序后台的合法域名里

### 3. 导入微信开发者工具

1. 微信开发者工具 → 小程序 → 导入项目
2. 目录选**本文件夹**（有 `project.config.json` 这一层）
3. AppID 用测试号，或你自己的 AppID
4. 点「编译」

## 功能说明

### AI 问答（真接口）

```
用户提问 → 后端检索知识库 top3 片段 → DeepSeek 按片段回答 → 前端逐字显示
```

- 密钥只在服务端，小程序里**没有任何密钥**
- 后端把命中的知识块作为 `cites` 返回，前端显示「依据 · 01-瓦斯防治」
- 网络失败 / 未配密钥 → 错误卡片，可「重试」或「转人工」
- 单次请求带最近 3 轮上下文，控制 token

### 答题（36 题，6 个岗位 × 6 题）

- 岗位：通用 / 采煤 / 掘进 / 通风 / 机电 / 运输
- 抽题：按岗位过滤 + 洗牌，每次 5 或 10 题
- 判分：选完立即出对错、解析、依据
- 错题：自动累积到 `wrongBook`（本地存储），个人中心可见
- 成绩：`quizBest` 记录最高分，同时上报 `/api/quiz` 入库

⚠️ **题库是示例内容**，正式上线前必须由矿安全科逐题审核，解析里的依据要换成矿上实际引用的条款号。

## 语音（当前：录音附件；正式小程序可开转文字）

**测试号没有「插件管理」，加不了「微信同声传译」**，所以在 `app.json` 里声明插件会直接编译/预览失败。
因此现在的策略是开关式：

- `app.json` **不带** `plugins` 字段；
- `utils/config.js` 里 `enableWechatSI: false`；
- 长按「语音」= 录一段音频上传成附件，页面提示“可补充文字让 AI 回答”；
- 点回答下方「听语音」会提示：朗读需要正式小程序 + 插件。

换成正式小程序后，三步开启边说边转文字 + 朗读：

1. 微信公众平台 → 设置 → 第三方设置 → 插件管理 → 添加「微信同声传译」（provider `wx069ba97219f66d99`，版本 `0.3.5`），等审核通过；
2. `app.json` 顶层加回：

   ```json
   "plugins": {
     "WechatSI": { "version": "0.3.5", "provider": "wx069ba97219f66d99" }
   }
   ```

3. `utils/config.js` 改 `enableWechatSI: true`，重新编译。

代码里的识别/TTS 逻辑（`pages/chat/chat.js` 的 `initVoice` / `voice`）已经写好，开关打开即用。

## 真机调试常见问题

- **登录/首页一直转圈**：先在调试器里取消所有断点，并关掉「在异常时暂停」——代码停在断点上时，页面就停在 loading 状态；
- **登录 12 秒超时**：手机与服务器不在同一网段（4G、别的 WiFi）时会这样，检查 WiFi 是否与服务器同网段；
- **改完代码后旧数据没刷新**：真机调试重新编译后，下拉首页刷新一次；首页 8 秒没加载完会显示「点这里重试」；
- **所有请求突然都不回**：结束调试 → 完全退出微信 → 重进（清掉小程序进程与残留的调试通道）。
